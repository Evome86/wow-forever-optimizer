# Forever Optimizer v3.1 — Level 60 / Eligibility Evidence

Overlay onto the existing repository. Upload `.github/workflows/forever-v31.yml`, all four `.py`/`.lua` scripts in `scripts/`, and three tests in `tests/`. Do **not** upload `__pycache__`.

In GitHub: Actions → **Forever v3.1 Level 60 and Eligibility Audit** → Run workflow. Download artifact `forever-v31-level-eligibility`, and provide `forever-v31-level-and-eligibility.json` for review.

The report separates `requiredLevel` (minimum player level) from `questLevel` (quest difficulty level), counts all quests vs IDs >=90000 across 1–60 and >60, shows maximum levels, and flags missing quest references and unparsed prerequisites. The 90k range is a technical classification, not proof of new content or playability. No Skyborne race-bit is guessed. No quests are declared playable and no optimized route is generated until semantics and in-game checks are complete.
